# Studio IORA Website

Premium static portfolio site for Studio IORA, built with HTML, CSS and a small JavaScript file.

## Structure

- `index.html` - full one-page website
- `css/styles.css` - responsive styling, layout and interactions
- `js/main.js` - mobile navigation and fade-in animation
- `assets/images/` - optimized Studio IORA visuals used by the site

## Run Locally

Open `index.html` in a browser, or serve the folder with any static server.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
